## Release notes（已发布）

```markdown
### 新增 / 改进

- **播放器圆润图标**：播放控制键换成圆润的矢量图标，不再受字体影响。外观页「播放器」
  分组有「圆润图标」开关（默认开），想用回旧样式关掉即可
- **取色新增「色族占比」**：外观页「主色来源」多一档。草地、海面这类明暗分散的照片封面
  不再被深色抢走主色，灰调封面也不会被上面的小色块带跑
- **播放器卡片弹入**：切歌时播放器卡片带弹入动效（动效分组可关）
- **切歌柔和过渡**：封面切换不再硬跳（动效分组可关）
- **组件动效优化** + 外观页图标放大；默认图标换成循环箭头
- **更新检查提速**：双源链路，国内网络也能正常拿到新版本提示
- 首页新增「作用域应用」统计；装完重启一次设备后，首页可显示框架的完整版本号

### 修复

- 歌词行进时封面壁纸偶发闪帧
- 播放键偶发闪烁
- 手电筒 / 相机转场时，背景偶尔变成纯色、拿不到封面

### 其他

- **安装包大幅瘦身**：39MB → 3.6MB
- **不再向外部发送任何统计数据**（旧版每次打开应用都会上传一份设备环境快照）
- 清理了大量与本模块无关的遗留代码，功能与设置均不受影响

### 安装说明

- 从旧版本**直接覆盖安装即可，不需要卸载**（卸载会清空配置）
- 装完后重启一次 SystemUI 生效；若状态异常，在模块管理器里确认已勾选
  `com.android.systemui` 与 `com.miui.miwallpaper` 作用域
- 适配：澎湃 OS 3（Android 16）
```
