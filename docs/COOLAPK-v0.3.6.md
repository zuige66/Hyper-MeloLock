## 正文（可直接粘贴）

Hyper MeloLock v0.3.6：歌词、歌名、歌手同屏，播放器卡片可隐藏封面，密码界面也沉浸

澎湃 OS 3（Android 16）的锁屏沉浸式音乐模块。

【新增 / 改进】

1. 歌词、歌名、歌手三者同屏：播放器卡片副行新增「歌手 / 歌名」。放歌词时主行是当前歌词句、副行是歌手和歌名，一次看全，不会再出现「一放歌词就不知道放的哪首」。不习惯的可以在「播放器」分组关掉，回到原来的两行
2. 播放器卡片可隐藏专辑封面：「播放器」分组新增「隐藏专辑封面」，打开后卡片左侧的小封面消失，歌词与歌名歌手两行水平居中，锁屏更干净。**注意：点小封面直接跳音乐 App 的快捷入口会随封面一起消失**
3. 逐句歌词：播放带歌词的曲目时，播放器主行跟着播放进度一句一句走；前奏与广告句自动跳过，第一句之前显示歌名
4. 密码界面封面沉浸：输解锁密码时背景同样用当前专辑封面，不再闪回原生壁纸
5. 长歌名 / 歌手名自动滚动：文字超出卡片宽度时自动跑马灯，滚动速度与滚动前停顿都能调；长文本也不会被省略号切掉
6. 播放键换成圆润矢量图标；上一首 / 下一首是双三角，暂停是两根圆角竖条
7. 原生播放器模式（可选）：锁屏直接用系统媒体卡，跟其他通知一样折叠，不再重复做一套卡片
8. 隐藏充电文案：锁屏底部那行充电提示可以单独关掉（默认关）
9. 播放器卡片新增诊断报告卡片：模块在锁屏里装没装上、为什么没生效，展开就能看到，一键复制后发群里即可，不需要数据线 / root / adb

【修复】

- 通知页退出后再亮屏，媒体卡偶发残留在染色状态
- 沉浸式与通知页来回切换时，原生播放器栈偶发被打回隐藏
- 时钟小时数偶发消失（只剩分钟）
- 快速亮屏 / 解锁时闪一下原生壁纸
- 歌词里的 App 广告句（开头几秒那句）不再显示

【怎么装】

- 旧版本直接覆盖安装即可，不用卸载（卸载会清空你的配置）
- 装完重启一次 SystemUI 生效
- 在模块管理器里确认已勾选 `com.android.systemui`、`com.miui.miwallpaper` 两个作用域
- 模块默认关闭，装完记得在 App 里打开总开关、勾选你的音乐应用

【适配】

只适配澎湃 OS 3（Android 16），换机型或换 ROM 版本不会生效。本次主要在 Redmi Note 9 Pro（OS3）上验证。逐句歌词目前实测 QQ 音乐可用，其他播放器取决于它是否向系统提供歌词数据。
