## Release notes（建议原文）

```markdown
### 新增 / 改进

- **通知页染色**：锁屏上的通知卡片和媒体卡跟着专辑封面取色，整页色调与封面统一；
  桌面下拉的通知栏也走同一套配色，不再各过各的
- **通知页独立底色**：不想跟播放器同色的，可以在「通知页」分组单独挑底色、单独选取色风格
- **取色风格三档**：时间、日期、签名、各卡片、入口胶囊都能各自选
  「低饱和磨砂 / 原色 / 更鲜艳」，配合三档主色来源（最鲜艳 / 占比 / 色族占比）自由搭配
- **设置页重新分组**：「跟随封面」统一叫「全局取色」，主开关置顶、下拉常驻、滑条收底，
  说明文字全部精简
- **隐藏相机 / 手电筒**：锁屏底部这两个图标可以单独关掉（默认关）
- **永不息屏**：想一直欣赏沉浸式页面就打开它（全局分组）
- **新装默认配色微调**：主色来源默认「色族占比」、入口胶囊默认低饱和磨砂、
  播放器卡片弹入默认关闭。**老用户配置不受影响**

### 修复

- 亮屏偶发「慢一拍」、锁屏壁纸闪一帧
- 开屏、下拉通知栏的偶发卡顿
- 解锁后原生时钟的小时数偶发消失（只剩分钟）
- 通知页媒体卡偶发卡在黑底（快速切页后）
- 「返回播放器 / 展开通知」文字黑白闪烁；胶囊颜色与通知页对不上
- 通知页息屏再亮屏会停在通知页不回播放器
- 关闭模块后通知页颜色偶发残留不还原

### 其他

- 安装包约 3.6MB
- 不向外部发送任何统计数据

### 安装说明

- 从旧版本**直接覆盖安装即可，不需要卸载**（卸载会清空配置）
- 装完后重启一次 SystemUI 生效；若状态异常，在模块管理器里确认已勾选
  `com.android.systemui` 与 `com.miui.miwallpaper` 作用域
- 适配：澎湃 OS 3（Android 16）
```
