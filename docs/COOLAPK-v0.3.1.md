## 正文

项目：Hyper MeloLock

介绍：hook，改系统界面。仿 iOS，大 R 角，通知正常，字体大小 / 圆润 / 颜色 / 间距可调节。

版本：v2.2

**测试环境**
- 机型：Redmi Note 9 Pro
- 系统：澎湃 OS 3 OS3.0.303.0.WNKCNXM（Android 16）
- 框架：Vector（需要 root）
- 作用域：`com.android.systemui` + `com.miui.miwallpaper`

**本次更新**

新增
- 封面改为真正的壁纸，系统毛玻璃效果可取到专辑色
- 时钟上方日期行（含农历）与自定义签名行，独立开关
- 播放器底色 7 档，支持跟随封面取色；浅色档自动配深字
- 文字颜色 7 档，可选跟随封面
- 取色支持磨砂 / 鲜艳两种风格，主色来源可选占比优先
- 时钟描边加粗滑杆
- 关于页检查更新；外观页改折叠卡片，支持分组恢复默认

优化
- 外观参数即时生效，无需重启 / 灭屏亮屏 / 重开开关
- 修复解锁瞬间闪原生壁纸
- 修复手电筒 / 相机转场掉帧
- 修复快速亮屏先露原生锁屏

**安装**
1. 两个作用域都要勾，勾完重启手机
2. App 首页点状态卡开启开关
3. 「应用」页勾选音乐播放器（默认一个都不勾）
4. 播放带封面的歌曲，熄屏再点亮

**限制**
- 仅适配上述机型与系统版本，其他环境保持原生锁屏
- 左半屏上滑解锁失效，右侧、指纹、电源键正常
