## 正文

### 锁屏上那块最大的屏，值得被音乐占满

Hyper MeloLock 是给**澎湃 OS 3** 做的锁屏沉浸式音乐覆盖层。

锁屏不再是"原生大时钟 + 底部一条小通知"，而是整屏专辑封面、大号时间，和一套完整的播放控制。

[配图①：锁屏播放器实拍]

它**不修改任何播放器**，也不改系统 APK、不动你的壁纸和通知数据，媒体信息和播放控制全走系统标准接口。拿不到有效媒体就自动退回原生锁屏，不会把你锁在屏外面。

---

### 这次更新了什么

**封面真的变成壁纸了**

以前是"看起来铺满了"，但系统那些液态玻璃时钟、通知卡的毛玻璃，采样的始终是系统壁纸，糊不出专辑色。这版封面**就是**壁纸了，那些效果终于能吃到专辑的颜色。顺带解锁时那个"早了露壁纸、晚了挡动画"的别扭劲儿也没了。

**解锁不闪原生壁纸**

v0.2 解锁瞬间会闪一下系统壁纸，很膈应。现在跟着系统动画一起走，干净了。手电筒、相机的转场也不卡了，快速亮屏也不会先露一下原生锁屏。

**时钟上面可以加日期和签名了**

- 日期行：公历 + 周几 + **农历**（`6月28日周六 · 乙巳年六月初四`），跨零点自动翻
- 签名行：随便写一句自己的话

两行各自独立开关，字号、粗细、颜色都能调。

**配色能跟着专辑走**

播放器卡片底色 7 档（深色 / 墨蓝 / 浅色 / 蓝灰 / 淡紫 / 淡粉 / 跟随封面），选浅色时文字会自动变深，不会看不清。

时间、日期、签名、通知入口的文字颜色也是同一套 7 档。选"跟随封面"会**实时从专辑图里取主色**，还能细调：

- 取色风格：低饱和磨砂 / 鲜艳原色，每项独立
- 主色来源：最鲜艳优先 / 占比优先（后者不容易被封面上一点点缀色带偏）

**时钟能更粗了**

有反馈说圆体字拉满还是细，查了才发现是字体本身的字重上限就到那了。所以加了一根描边加粗滑杆，在字外面补一圈，0 就是原来的样子。

**改参数不用再重启了**

v0.2 最烦的一点，改完外观得灭屏亮屏、甚至关掉再开才生效。现在改完回锁屏就是新的。

另外关于页加了**检查更新**（国内网络也能正常用），外观页改成折叠卡片，每组都能一键恢复默认。

### 完整功能

- **锁屏沉浸播放器**：大号时间 + 封面背景 + 完整控制条，暂停时保留最后一帧而不是撤掉整层
- **逐项调参**：时间 / 封面 / 播放器的大小、圆角、间距、底色，都能实时调
- **日期行 + 签名行**：含农历，各自独立开关
- **跟随封面取色**：主色实时从专辑图提取，风格可选
- **共享元素切换**：点"展开通知"时卡片滑走、通知同向淡入，像同一个组件在移动
- **切歌不掉原生锁屏**：换歌的空窗期保留上一帧，全程不闪回
- **点封面直达音乐 App**：先弹解锁验证，通过后直达当前播放器
- **锁屏禁用左下拉**：避免和原生通知面板叠在一起

### 怎么装

1. 装 APK
2. 在 Vector / LSPosed 里启用模块，**作用域勾这两个**：
   - `com.android.systemui`
   - `com.miui.miwallpaper`
   勾完重启手机
3. 打开应用，点首页状态卡开启开关
4. 在「应用」页**勾选你的音乐播放器**（默认一个都不勾，必须手动选）
5. 放首带封面的歌，熄屏再点亮

> ⚠️ **升级用户注意**：作用域比 v0.2 多了一个，勾完要**重启手机**才会生效。只在管理器里勾上不算数。

---

### 先说清楚限制，能接受再装

- **机型硬门禁**：只在 **Redmi Note 9 Pro** + **澎湃 OS 3 / Android 16**（系统版本 `OS3.0.303.0.WNKCNXM`）上验证过。别的机型、或者这台机器升了系统版本，会主动放弃、保持原生锁屏——不是 bug，是设计如此
- 需要 root + Vector / LSPosed
- **左半屏上滑解锁会失效**，这是"禁用左下拉"的代价。右半边上滑、指纹、电源键都正常
- App 里「Xposed 框架」一行固定显示"未知"，是读取方式的限制，不是故障
