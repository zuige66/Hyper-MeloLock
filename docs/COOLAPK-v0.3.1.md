## 正文

项目：Hyper MeloLock

介绍：hook，改系统界面。仿 iOS，大 R 角，通知正常，字体大小 / 圆润 / 颜色 / 间距可调节。

版本：v2.2

**测试环境**
- 机型：Redmi Note 9 Pro
- 系统：澎湃 OS 3 OS3.0.303.0.WNKCNXM（Android 16）
- 框架：Vector（需要 root）
- 作用域：`com.android.systemui` + `com.miui.miwallpaper`

---

### 这次更新了什么

**1. 封面变成真壁纸了**

以前是看着铺满了，其实只是在锁屏上叠了一层，系统那些液态玻璃时钟、通知卡的毛玻璃采样的还是系统壁纸，糊不出专辑的颜色。

这版封面就是真正的壁纸了，那些效果终于能吃到专辑色。顺带把解锁时"早了露原生壁纸、晚了挡桌面动画"这个别扭劲儿也一并解决了。

**2. 解锁不再闪原生壁纸**

上一版解锁那一下会闪一张系统原生壁纸，很膈应。现在跟着系统动画一起走，干净了。

顺手修的还有：手电筒和相机的转场不再掉帧，快速亮屏也不会先露一下原生锁屏。

**3. 时钟上面能加日期和签名了**

- 日期行：公历 + 周几 + **农历**（`6月28日周六 · 乙巳年六月初四`），跨零点自动翻
- 签名行：随便写一句自己的话

两行各自独立开关，字号、粗细、颜色都能调。

**4. 配色能跟着专辑走**

播放器卡片底色扩到 7 档：深色 / 墨蓝 / 浅色 / 蓝灰 / 淡紫 / 淡粉 / **跟随封面**。选浅色时卡内文字会自动变深，不会出现浅底白字。

时间、日期、签名、通知入口的文字颜色也是同一套 7 档：跟随封面 / 白 / 黑 / 浅灰 / 暖黄 / 天蓝 / 粉。

选"跟随封面"会实时从专辑图里取主色，而且能细调：

- 取色风格：低饱和磨砂 / 鲜艳原色，每个颜色项独立
- 主色来源：最鲜艳优先 / 占比优先（后者不容易被封面上一点点缀色带偏）

**5. 时钟能更粗了**

有反馈说圆体字拉满还是细，查下来是字体本身的字重上限就到那了，再拉也没用。所以加了一根描边加粗滑杆，在字外面补一圈，0 就是原来的样子。

**6. 改参数不用再重启了**

上一版最烦的一点：改完外观得灭屏亮屏、甚至关掉再重新打开才生效。现在改完回锁屏直接就是新的，什么都不用重启。

另外：关于页加了**检查更新**（国内网络也能正常用），外观页改成了折叠卡片，每组都能一键恢复默认。

---

### 完整功能

- **锁屏沉浸播放器**：大号时间 + 封面背景 + 完整控制条，暂停保留最后一帧而不是撤掉整层
- **逐项调参**：时间 / 封面 / 播放器的大小、圆角、间距、底色，实时可调
- **日期行 + 签名行**：含农历，各自独立开关
- **跟随封面取色**：主色实时从专辑图提取，风格可选
- **共享元素切换**：点"展开通知"卡片滑走、通知同向淡入，像同一个组件在移动
- **切歌不掉原生锁屏**：换歌空窗期保留上一帧，全程不闪回
- **点封面直达音乐 App**：先弹解锁验证，通过后直达当前播放器
- **锁屏禁用左下拉**：不和原生通知面板叠在一起

---

### 装完还要做这几步，不然没反应

1. 上面**两个作用域都要勾**，只勾第一个封面壁纸化不生效
2. 勾完**重启手机**——管理器里勾上只是声明，进程没重启就注入不进去
3. 打开 App，点首页那张状态卡打开开关
4. 进「应用」页**勾选你的音乐播放器**（默认一个都不勾，必须手动选）
5. 放一首带封面的歌，熄屏再点亮

> 升级用户注意：作用域比上一版多了一个 `com.miui.miwallpaper`，勾完要重启手机才生效。

---

### 已知限制（先说清楚）

- 只认上面那套环境。别的机型、或者这台机器升了系统版本，会直接保持原生锁屏——不是 bug，是设计如此
- 左半屏上滑解锁会失效，这是禁用左下拉的代价。右半边、指纹、电源键都正常
- App 里「Xposed 框架」一行固定显示"未知"，是读取方式的限制，不是故障
