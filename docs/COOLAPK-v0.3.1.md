## 正文

### 锁屏上那块最大的屏，值得被音乐占满

Hyper MeloLock 是给**澎湃 OS 3**做的锁屏沉浸式音乐覆盖层。

锁屏不再是"原生大时钟 + 底部一条小通知"，而是整屏专辑封面、大号时间，和一套完整的播放控制。

[配图①：锁屏播放器实拍]

它**不修改任何播放器**，也不改系统 APK、不动你的壁纸和通知数据——只给 `com.android.systemui` 注入一个锁屏视图适配器，媒体信息、封面、播放控制全部走 Android 标准的 `MediaSession`。

默认关闭、**失败关闭**：找不到锁屏视图、或者媒体数据无效时立刻恢复原生锁屏。不会把你锁在屏外面。

---

### 这次更新了什么（v0.2 → v0.3.1）

#### 一、封面真的变成「壁纸」了

这是这一版最大的变化。

以前在 SystemUI 里叠一层 View 当背景，看起来是铺满了，但 **MIUI 那个液态玻璃时钟、还有通知卡的毛玻璃模糊，采样的是壁纸窗口**——叠再多层 View 它们也采样不到，永远只能糊到系统壁纸。

这一版改成进 `com.miui.miwallpaper` 进程，在 GL 上传点把专辑图替换成壁纸纹理。封面从此**就是**壁纸，那些玻璃效果终于能真正"吃"到专辑色。

顺带的收益：解锁时"早掀盖会露出原生壁纸、晚掀盖又会挡住桌面入场动效"这个两头堵的死结，从结构上消失了。

#### 二、解锁不闪原生壁纸了

v0.2 有个很膈应的问题：解锁那一瞬间会闪一下系统原生壁纸。

真机抓日志查出来的根因是——**系统在解锁时会把整棵锁屏根视图置为不可见**，挂在里面的图层连绘制都不参与，自己怎么设可见性都没用。

现在改成：解锁信号一到就把封面挪出锁屏根，跟着系统动画做交叉溶解，时长对齐系统退场动画。手电筒 / 相机的转场也顺手修了——不再往里插自己的全屏视图（旧版实测掉到 20fps），改成替换 MIUI 那层遮罩的背景。

另外，快速亮屏时不再先露一下原生锁屏，熄屏暗期就把场景预建好了。

#### 三、锁屏上多了日期行和签名行

时钟上方可以加两行，**各自独立开关**：

- **日期行**：公历 + 周几 + **农历**（比如 `6月28日周六 · 乙巳年六月初四`），走系统自带的 ICU 农历，跨零点自动翻
- **签名行**：随便写点什么，锁屏上留一句自己的话

字号、粗细、颜色都能单独调。

#### 四、配色可以跟着专辑走了

播放器卡片底色从 1 档扩到 **7 档**：深色 / 墨蓝 / 浅色 / 蓝灰 / 淡紫 / 淡粉 / **跟随封面**。选浅色档时卡内文字会自动换深色，不会出现浅底白字看不清的情况。

时间、日期、签名、通知入口的文字颜色也统一成同一套 7 档：跟随封面 / 白 / 黑 / 浅灰 / 暖黄 / 天蓝 / 粉。

**"跟随封面"是从专辑图里实时取的主色**（Palette 提取，后台线程跑，不占主线程）。取色还能细调：

- **取色风格**：低饱和磨砂 / 鲜艳原色，每个颜色项独立
- **主色来源**：最鲜艳优先 / 占比优先（后者会先挑封面里占比最大的那块色调，再在里面选最鲜艳的，避免被封面上一点点缀色带偏）

#### 五、时钟能更粗了

有反馈说圆体字体的粗细拉满还是细。查了字体的 `fvar` 表才发现：**圆体字重的 wght 轴上限就是 700 / 800，滑杆拉到 900 也被字体本身钳住**，没有更粗的空间了。

所以加了一根**描边加粗**滑杆（0~8dp），在字体外面补一圈描边来突破字重上限，0 就是原来的样子。

#### 六、改参数不用再重启了

v0.2 最烦的一点：改完外观得灭屏亮屏、甚至关掉再重新打开模块才生效。

根因找得挺深——SystemUI 侧读配置时拿到的是**它自己进程里那份永远是空的 SharedPreferences**，所以"配置有没有变"这个比对恒等于"没变"，形同虚设。修掉之后，现在是**改完回锁屏就是新外观**，什么都不用重启。

顺带：关于页加了**检查更新**（GitHub 拉不到会自动回退国内静态源，国内网络也能用），外观页改成折叠卡形态、每组都能一键恢复默认。

### 完整功能一览

- **锁屏沉浸播放器**：大号时间 + 封面模糊背景 + 完整控制条；暂停时保留最后一帧而不是撤掉整层
- **逐项调参**：时间/封面/播放器的字号、粗细、圆润、圆角、间距、底色，全都能实时调
- **日期行 + 签名行**：公历+周几+农历，自定义签名，各自独立开关
- **跟随封面取色**：主色实时从专辑图提取，风格与主色来源可选
- **共享元素切换**：点"展开通知"时播放器卡片滑走、通知同向淡入，像同一个组件在移动
- **切歌不掉原生锁屏**：换歌有约 300ms 拿不到封面的空窗期，期间保留上一帧 + 1.5 秒宽限
- **点封面直达音乐 App**：锁屏上点小专辑封面，先弹解锁验证、通过后直达当前播放器
- **锁屏禁用左下拉**：沉浸场景显示期间吃掉左半屏下拉手势，避免自绘层和原生通知面板叠在一起

### 怎么装

1. 装 APK（下载地址在文末）
2. 在 Vector / LSPosed 里启用模块，**作用域勾这两个**：
   - `com.android.systemui`（锁屏覆盖层本体，**必须**）
   - `com.miui.miwallpaper`（封面壁纸化靠它，不勾就还是旧版那种叠 View 的效果）
3. 重启 SystemUI 或重启手机
4. 打开 App，首页点状态卡开启开关
5. 在「应用」页**勾选你的音乐播放器**（默认一个都不勾，必须手动选）
6. 放一首带封面的歌，熄屏再点亮

> ⚠️ **升级用户特别注意**：作用域比 v0.2 多了一个 `com.miui.miwallpaper`。只在管理器里勾上还不算完，**要把壁纸进程也重启一次**（重启手机最省事），新入口才会被注入。

### 先说清楚限制，能接受再装

- **机型硬门禁**：只在 **Redmi Note 9 Pro（`gauguinpro`）** + **澎湃 OS 3 / Android 16**（构建指纹 `OS3.0.303.0.WNKCNXM`）上验证过。模块按精确构建指纹判断，**其他机型、或这台机器升了 ROM 版本，会主动放弃覆盖、保持原生锁屏**——不是 bug，是设计如此
- **需要 root + Vector / LSPosed**
- **左半屏上滑解锁会失效**：这是"禁用左下拉"的代价。用右半边上滑、指纹或电源键解锁都正常
- 模块里的「Xposed 框架」一行在 legacy 模式下固定显示"未知"，是读取方式的限制，不是故障
