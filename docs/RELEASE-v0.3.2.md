# v0.3.2 发布说明

> 用途：GitHub Release v0.3.2 的正文，直接复制到 Release 描述框；
> QQ 群 / 酷安更新说明也可在此基础上删减。

## 更新内容

- **开放更多机型**：不再限制单一设备，澎湃 OS 3 各机型均可启用（多机型测试阶段；
  未验证机型会显示提示，如遇锁屏显示异常请反馈）
- **修复下载失败**：部分网络下能检测到新版本、但 APK 下载失败的问题——下载会自动
  切换国内源重试
- **首页信息秒出**：系统版本、Xposed 框架、设备型号打开即显示，不再等待加载
- **「关于」页**：新增 QQ 交流群入口；开发者卡片改为点击展开（GitHub / Blog）；
  「检查更新」移到「关于模块」分组
- 移除未实装的「恢复与备份」占位项

## 说明

- 覆盖安装即可升级（正式签名一致）；装完建议确认 Xposed 管理器作用域仍勾选
  `com.android.systemui`（封面壁纸化需 `com.miui.miwallpaper`），改代码行为要重启
  SystemUI 才生效。
- 非小米机型 / 其他澎湃 OS 3 设备属测试阶段：遇到锁屏显示异常请到
  [Issues](https://github.com/zuige66/Hyper-MeloLock/issues) 或 QQ 群反馈，
  最好附上 `adb logcat -d | grep MeloLock` 的输出。
