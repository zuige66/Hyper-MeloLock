## 正文（可直接粘贴）

Hyper MeloLock v0.3.4：通知页跟着专辑变色，取色多了三档风格，设置页重新分组

澎湃 OS 3（Android 16）的锁屏沉浸式音乐模块。

【新增 / 改进】
1. 通知页染色：锁屏上的通知卡片和媒体卡都会跟着专辑封面取色，整页色调跟封面统一，不再各过各的；桌面下拉的通知也走同一套配色
2. 通知页独立底色：不想跟播放器同色的，可以在「通知页」分组单独挑一个底色，取色风格也能单独选
3. 取色风格多三档：时间、日期、各个卡片都能各自选「低饱和磨砂 / 原色 / 更鲜艳」，配合原本的三档主色来源（最鲜艳优先 / 占比优先 / 色族占比），配色更自由
4. 设置页重新分组：「跟随封面」统一叫「全局取色」，主开关置顶、下拉常驻、滑条收在下面，每项说明也更短更清楚
5. 隐藏相机 / 手电筒：锁屏底部这两个图标可以单独关掉（全局分组，默认关）
6. 永不息屏：想一直看着封面就打开它，锁屏不再自动息屏（全局分组）
7. 新装默认配色微调：主色来源默认「色族占比」、入口胶囊默认低饱和磨砂、播放器卡片弹入默认关（老用户配置不受影响）

【修复】
- 亮屏偶发慢一拍、锁屏壁纸闪一帧
- 开屏、下拉通知栏的偶发卡顿
- 解锁后原生时钟的小时数偶发消失（只剩分钟）
- 快速切换沉浸式 / 通知页时，媒体卡偶发卡在黑底
- 「返回播放器 / 展开通知」文字黑白闪烁；胶囊颜色与通知页对不上
- 通知页息屏后再亮屏，会停在通知页不回播放器
- 文字和图标在深浅色切换时偶发闪一下
- 关闭模块后通知页颜色偶发残留不还原

【其他】
- 安装包依旧约 3.6MB，下载安装都快
- 不上报任何统计数据

【怎么装】
- 旧版本直接覆盖安装即可，不用卸载（卸载会清空你的配置）
- 装完重启一次 SystemUI 生效
- 在模块管理器里确认已勾选 com.android.systemui、com.miui.miwallpaper 两个作用域
- 模块默认关闭，装完记得在 App 里打开总开关、勾选你的音乐应用

【适配】
只适配澎湃 OS 3（Android 16），换机型或换 ROM 版本不会生效。本次主要在 Redmi Note 9 Pro（OS3）上验证。
